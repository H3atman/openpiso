# Security

Report suspected vulnerabilities privately using [GitHub private vulnerability
reporting](https://github.com/H3atman/openpiso/security/advisories/new).
Do not open a public issue or publish exploit details before coordinated disclosure.

Include affected versions/platforms, reproduction steps, impact, and sanitized
logs. Never send real customer records, device secrets, passwords, or signing keys.
Use the latest release; Admin mutation endpoints belong on a trusted LAN, not
the public internet. If private reporting is unavailable, wait for a private
channel rather than posting sensitive details publicly.
