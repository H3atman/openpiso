# What you need

Check this list before you start. Every item here is needed to run OpenPiso in your shop.

## Computers

- **Windows on every computer.** Every computer must run 64-bit (x64) Windows.
- **One Server PC.** This is the computer that runs the Central Terminal. Customers do not rent it. It must stay on the whole time the shop is open, because it keeps the shop's records and counts the coins.
- **Your rental PCs.** Each PC that customers rent runs the Client.

## The Server PC's COM header

The coin slot plugs into a COM header on the Server PC's motherboard. The header is a small row of pins, often labelled **JCOM1**.

- Check the motherboard for this header before you buy anything else.
- USB-to-serial adapters are not supported. The coin slot must connect to the COM header on the motherboard.

## The coin slot

- Any Allan or generic multi-coin slot works.
- The coin slot runs on 12 V. It takes this power from the Server PC's power supply, through a Molex connector.

## Your shop's network

- The Server PC and every rental PC must be on the same local network, connected through a router or a switch.
- You do not need internet to run the shop.

## Something to open the Web Admin

You manage the shop from the Web Admin, which opens in a web browser. Use a phone, a tablet or another computer that is on the same network as the Server PC.

You should now have everything on this list ready.
