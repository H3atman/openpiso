# OpenPiso 0.12.1

## New

- Releases are now published from the public source repository.
- The Admin now sends one anonymous daily summary to PostHog Cloud US: a random
  install ID, the Admin version and how many PCs connected. No shop, customer or
  money data. Always on, no opt-out, kept for one year. See the installation
  guide's Telemetry section.

## Fixed

- No shop-owner-facing fixes.

## Changed

- Updated documentation for the source release feed and legacy bridge rollout.
